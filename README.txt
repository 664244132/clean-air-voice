1) ติดตั้ง Node.js 18+ หรือ 20+
2) เปิดโฟลเดอร์นี้ใน Terminal
3) รัน: npm install
4) คัดลอก .env.example เป็น .env
5) ใส่ GEMINI_API_KEY ใน .env
6) วางไฟล์วิดีโอชื่อ clean-air-for-life.mp4 ในโฟลเดอร์ public
7) รัน: npm start
8) เปิด Chrome/Edge ที่ http://localhost:3000
9) กด เริ่มระบบ และอนุญาตไมโครโฟน
10) พูด “ไอที” -> ระบบตอบ “คุณต้องการให้ทำอะไร” -> พูด “Clean Air for Life”
